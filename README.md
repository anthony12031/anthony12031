**Cursor** and **Claude Code** plugin that standardizes **language-agnostic** AI-assisted development: the same commands, skills, and automation across repositories—without tying you to one stack.

### Capabilities

- **Slash commands:** `/init-repo`, `/build-feature`, `/design`, `/fix-bug`
- **Skills** and **subagents** for structured, repeatable work
- **Language rules**, **hooks**, and **Figma MCP**

### Quick start

**Cursor**

1. Clone the repository and run `install.sh` once.
2. The script links `~/.cursor/plugins/local/` and mirrors commands, agents, and skills into `~/.cursor/` for use in any repository you open.

**Claude Code**

1. Add the GitHub repository as a **marketplace** source.
2. Install the plugin, then follow the copy-paste commands in the repository README.
